# SOLAR SLING — Orbital Slingshot Arcade

引っ張って弾くだけの直感操作 × 空中スローモーション × 連続貫通＆壁反射コンボのシングルプレイ・ブラウザゲームです。  
外部ライブラリ・外部画像・外部音声ファイルに一切依存せず、`index.html` 1枚でスマホでもPCでも高速に動作します。

## 特徴

- **誰でも1秒でわかる操作 & 深い中毒性**
  - 画面のどこからでも引っ張って離すだけ（スマホ片手操作対応、指で自機が隠れない設計）。
  - 空中で長押しすると時間が **10%のスローモーション** になり、壁反射（BANK SHOT）や複数貫通（TRIPLE / NOVA）を自在に狙えます。
- **リッチな映像とプロシージャル音響**
  - Canvas 2D による軌跡リボン、ヒットストップ、画面振動、破片物理、衝撃波、壁面リップル、Overdrive演出。
  - Web Audio API による完全合成サウンド（コンボに応じてペンタトニックスケールで上昇するチャイム音、スローモーション時のBGMローパスフィルター演出、116 BPM の動的アンビエントBGM）。
- **維持費0円のオンラインランキング（Google Apps Script + Google Sheets）**
  - サーバー代・DB代ゼロ。付属の `gas/Code.gs` を Google スプレッドシートに貼ってデプロイするだけで「全期間 TOP」「今週 TOP」のオンラインランキングが稼働します。
  - GAS未設定時は自動で「ローカル＋ライバルBOTモード」で動作するため、設定前でもすぐ遊べます。

## 遊び方

| 操作 / 要素 | 内容 |
|---|---|
| **ドラッグして離す** | ストライカーを発射（最大3チャージ、ターゲット破壊や時間経過で回復） |
| **空中長押し** | 時間がスローになり、壁反射1回分までの軌道予測ラインが表示される |
| **BANK SHOT** | 壁や青いバンパーで跳ね返ってから破壊するとスコア **1.5倍** |
| **OVERDRIVE** | ゲージ満タンで7秒間発動：**スコア2倍・無限チャージ・赤い機雷も破壊可能** |
| **WAVE CLEAR** | ターゲット全破壊で **+5.0秒** 延長＆ボーナススコア |
| **キーボード（PC）** | `M` ミュート / `P` or `Esc` 一時停止 / `R` リスタート |

## 維持費0円オンラインランキングの設定方法（約3分）

1. [Google スプレッドシート](https://sheets.new) を新規作成します。
2. 上部メニューの **拡張機能 > Apps Script** を開きます。
3. エディタ内の既存コードを削除し、[`gas/Code.gs`](./gas/Code.gs) の中身をすべて貼り付けて保存します。
4. 右上の **デプロイ > 新しいデプロイ** をクリックします。
   - 種類の選択: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. **デプロイ** を押し、権限を承認すると `https://script.google.com/macros/s/xxxxx/exec` のようなURLが発行されます。
6. ゲーム側の連携方法は2通りあります：
   - **公開前に埋め込む（おすすめ）**: `index.html` 内の `CONFIG.GAS_ENDPOINT` にURLを貼り付けて保存。
   - **手元で試す**: ゲームのタイトル画面やランキング画面の **⚙ GAS設定** からURLを貼り付けて「保存して接続テスト」。

> **技術メモ**: ブラウザから GAS への `POST` は `Content-Type: text/plain;charset=utf-8` を使うことで CORS プリフライト（`OPTIONS`）を回避しており、GitHub Pages やローカルHTMLからでもそのまま通信できます。また、GAS 側で `LockService` による排他制御・スコア範囲チェック・軽量署名チェックを行っています。

## 無料公開方法

`index.html` は完全単一ファイルなので、以下のいずれかに置くだけで無料で公開できます。

- **GitHub Pages**: リポジトリに `index.html` を push して Pages を有効化
- **Cloudflare Pages / Netlify / Vercel**: フォルダをドラッグ＆ドロップするだけで即時公開
